~/projects

Projects

OSI & TCP/IP Layer Demonstrator

Computer Networks subject project — Group 3

Problem

Network layering and encapsulation are abstract ideas that are hard to picture from a textbook.

Solution

A software simulation that shows one message travelling from PC-A through Switch → Router → Switch to PC-B, with each layer adding its header on the way down and removing it on the way up, ending with a CRC check that proves the message arrived unchanged.

TechnologiesPython, HTML/CSS/JavaScript

Key features
  • Step-by-step encapsulation and decapsulation
  • Header-by-header explanation (AH / PH / SH / TH / NH / DH / DT)
  • CRC error check
  • Interactive visual version
GitHub Live Demo
